# Hero Images

Place the homepage hero image here.

## What to put here

A single atmospheric image used as the hero visual on the homepage. This can be:
- A styled room shot (wide, calm, editorial)
- A detail shot — a surface, a corner, natural light on linen
- Melody's portrait in a home setting

## Filename

Name it `hero.jpg` (or `hero.webp` for better performance).

## Recommended size

- **Minimum:** 1600 × 900px
- **Ideal:** 2400 × 1200px
- **Aspect ratio:** 2:1 or wider (landscape)
- **Format:** JPG or WebP
- **File size:** aim for under 400KB (compress before uploading)

## How to use it

Once you've added the image, update the hero section in `index.html` to reference it:

```html
<img src="/images/hero/hero.jpg" alt="The Three Edit" />
```

Or use it as a CSS background if you prefer a full-bleed treatment.
