# About Page Images

Place Melody's photo here.

## What to put here

A portrait or lifestyle image of Melody for the About page. It should feel:
- Quiet and editorial — not posed or studio-style
- In a home setting: reading, arranging objects, by a window
- Natural light preferred

## Filename

Name it `melody.jpg` (or `melody.webp`).

## Recommended size

- **Minimum:** 800 × 1000px
- **Ideal:** 1200 × 1500px
- **Aspect ratio:** 4:5 or 3:4 (portrait orientation works best)
- **Format:** JPG or WebP
- **File size:** aim for under 300KB

## How to use it

Once added, update `about/index.html` to reference it:

```html
<img src="/images/about/melody.jpg" alt="Melody, founder of The Three Edit" />
```
